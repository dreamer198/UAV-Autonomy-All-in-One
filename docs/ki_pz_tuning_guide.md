# 如何整定 `ki_pz`（竖直积分增益）

> 这是一份**照着做**的操作指南，目标：在真机上找到一个合适的 `ki_pz`，让无人机在 OFFBOARD 下**不再随电池电压下降/载荷变化而缓慢掉高**。
>
> 原理（为什么要积分项、它如何消除稳态高度误差）见 [se3_controller.md §8.7](se3_controller.md#87-竖直积分项可选默认关闭) 以及 §8.1–§8.2 的位置/速度环说明。本文只讲**怎么调**。

---

## 先读导引

先确认你遇到的是不是 `ki_pz` 该管的问题：

| 现象 | 该看哪篇 |
|---|---|
| OFFBOARD 悬停一开始还行，随后随电池/载荷变化慢慢掉高 | 本文，整定 `ki_pz` |
| 一切到 OFFBOARD 就明显掉/蹿 | 先看 [se3_controller.md](se3_controller.md) 的 `hover_percent` 和推力标定 |
| 悬停稳，但跟踪 Diff-Planner 轨迹时爬升段掉高 | 看 [trajectory_tracking_altitude.md](trajectory_tracking_altitude.md)，多半是推力余量或里程计问题 |

本文的读法很直接：

| 步骤 | 对应章节 |
|---|---|
| 先知道积分项解决哪一种掉高 | §0、§2 |
| 飞前安全确认 | §1 |
| 真机整定步骤 | §3 |
| 判断调大还是调小 | §4、§5 |
| 固化配置 | §6、§7 |

核心目标不是“切 OFFBOARD 完全不掉一下”，而是：**允许一个小坑，然后几秒内平顺回到切入那一刻的高度，且不振荡、不顶油门。**

---

## 0. 一句话原理

固定的 `hover_percent` + 无积分的前馈/比例控制，面对「真实悬停油门随电压/重量漂移」这个**恒定偏置**，必然留一个非零稳态高度误差 → 缓慢掉高。**积分项**把这份缺口累积补上，使稳态高度误差归零（与 PX4 定点模式带的积分器同理）。`ki_pz` 就是这个积分项的增益，需按机整定。

---

## 1. 安全前提（务必先满足）

- [ ] **低空测试**：1.5–2 m，给「初始小坑」留余量。
- [ ] **手全程放在遥控器上**，随时可切回定点接管。
- [ ] 用**和实飞相同的载荷/电池配置**整定（悬停油门跟重量强相关）。
- [ ] 在线推力估计保持关闭：`SE3_ENABLE_THRUST_ESTIMATION=false`（本机架振动会让它发散）。
- [ ] 在真实 `SE3_HOVER_PERCENT` 下确认 `ki_pz=0` 时基础悬停本身不发散（先无回归，再加积分；测试时再临时压低 `hover_percent` 造缺口）。
- [ ] 积分项代码已编译进容器（见 [se3_controller.md](se3_controller.md) 部署说明）。

---

## 2. 测试原理：人为造缺口 + 用「切 OFFBOARD」当阶跃扰动

1. **故意把 `SE3_HOVER_PERCENT` 设低一点**（比真实悬停油门低 0.05–0.10）。这样基准推力不足，缺口当场存在，不用等几分钟电池沉。
2. 用遥控器**从定点(Position)切到 OFFBOARD**。控制器接管的瞬间会「保持当前高度」，但基准不够 → 先往下掉一点 → 看积分器能否把它拉回**切那一刻的高度**并稳住。
3. **关键设计**：积分器在**每次进 OFFBOARD 时会自动清零**（`resetIntegral()`）。所以：
   - 每次切都从积分=0 开始攒，**每次测试公平、可复现**；
   - 但也意味着**哪怕 `ki_pz` 完美，也一定有一个初始小坑**（积分必须先看到误差才能补偿）。**目标是「小坑 + 快速平顺回到原高」，不是零坑。**

> 这个「切 OFFBOARD」是个**阶跃**缺口，比真实电池缓慢下沉更狠。能干净通过它，慢速电池沉一定没问题——所以这样整定偏保守、足够。

---

## 3. 操作步骤

### 3.1 启动（不跑规划器、压低 hover_percent 造缺口）

在 Jetson 宿主执行（真实悬停 ~0.90 时，先压到 0.80）：

```bash
FCU_URL='serial:///dev/ttyACM0:57600' GCS_URL='udp://:14550@10.0.30.196:14550' \
START_DIFF_PLANNER=false START_SE3_CONTROLLER=true \
SE3_HOVER_PERCENT=0.80 \
./scripts/start_real_px4_mid360_fastlio.sh start
```

### 3.2 打开监视与调参（另开终端，进容器 `./docker/docker_run_real.sh shell`）

```bash
# 实时看下发油门：越界/饱和、是否在补偿
rostopic echo /mavros/setpoint_raw/attitude/thrust

# 在线调 ki_pz（图形滑块，推荐）
rosrun rqt_reconfigure rqt_reconfigure          # 选 /se3_controller_node，调 ki_pz

# 或命令行直接设
rosrun dynamic_reconfigure dynparam set /se3_controller_node ki_pz 0.2
```

高度可在 RViz 看，或：
```bash
rostopic echo -n1 /mavros/local_position/odom/pose/pose/position/z
```

### 3.3 迭代闭环

1. 定点模式手动带飞到 1.5–2 m 稳住。
2. 在 rqt 里设一个 `ki_pz`（从 **0.1** 起）。
3. **扳到 OFFBOARD**，观察：掉多深？多久回到切那一刻的高度？有没有过冲/振荡？
4. **扳回定点**（积分自动清零），改 `ki_pz`，重复第 2–3 步。
5. 按 **0.1 → 0.2 → 0.35 → 0.5** 翻倍式逼近，甜点多半落在 **0.2–0.4**。

> 进阶快速法：在 OFFBOARD 悬停中用手把飞机**轻轻下压 ~20 cm 再松手**，直接看恢复特性，比反复切模式更快。

---

## 4. 判读：怎样算合适

终点永远是「**回到切 OFFBOARD 那一刻的高度**」——只要 `ki_pz` 在稳定范围，稳态误差必然归零。你调的是**回升速度 + 不振荡**：

| `ki_pz` | 现象 | 动作 |
|---|---|---|
| 太小 | 坑深；**几十秒**才慢慢爬回原高（容易误以为「停在低处不动了」，其实在极慢回升） | 加大 |
| **合适** | 小坑 → **几秒内平顺回到原高**、不过冲；电压下降时油门自动上爬而高度不变 | ✅ 记下，固化 |
| 太大 | 冲过原高、高度上下「海豚式」**振荡**；油门跟着抖 | 调小（回退到上一档与它之间） |

> ⚠️ **别把「停在更低的高度不掉了」当成功**——那多半是 `ki_pz` 太小、还在极慢回升，或只是比例环把下沉刹住了。合适的标志是**回到原高**。

合适的 `ki_pz` 带来的最终效果：
- **高度自己稳住，与电量无关**：电压一路降，油门数值自动悄悄上爬，高度纹丝不动。
- 顺带修掉「满电时停在目标点上方」的偏差（停得正）。
- 被扰动后几秒平顺归位，全程无振荡。

---

## 5. 常见陷阱

1. **缺口造得太大**：`hover_percent` 压太低 → 初始坑很深很吓人，且回升时油门顶到 `max_output=1.0` **饱和**，抗饱和逻辑会**冻结积分**，你会看到「怎么加 ki 都恢复不动」的假象。→ 只压 0.05–0.10，并留足高度。
2. **把油门饱和当成 ki 不够**：先看 `thrust` 是否贴在 1.0。贴住=饱和受限，不是 ki 的问题。
3. **没回到原高就收手**：见第 4 节，要等它真正回到切换高度，别被「极慢回升」骗了。
4. **改了别的增益**：只动 `ki_pz`，`Kp_*` / `int_limit_z` 保持当前启动脚本和控制器配置（`int_limit_z=5.0` 给得很宽，正常不用动）。
5. **载荷/电池和实飞不一致**：换了配置悬停油门就变，整定要在实飞条件下做。

---

## 6. 固化（调好之后）

1. 把 `SE3_HOVER_PERCENT` **调回真实悬停油门**（如 ~0.90）——测试时压低只为造缺口，实飞要让基准贴近真实、让积分只兜电压漂移那一小部分。
2. 把整定好的值写进启动脚本默认：
   ```bash
   SE3_KI_PZ="${SE3_KI_PZ:-0.30}"   # 0.30 换成你测出来的值
   ```
   见 [scripts/start_real_px4_mid360_fastlio.sh](../scripts/start_real_px4_mid360_fastlio.sh)。
3. **持久化到镜像**：容器内的增量编译在 `docker_run_real.sh run/restart` 后会丢失。最终用 `./docker/docker_run_real.sh build` 重建镜像固化（Jetson 上较慢，整定完再做）。

```bash
# 看 PX4 学到的悬停油门（注意：0.5 多半是未标定的出厂默认，仅供参考）

# 关掉积分回到无积分模式（任何时候的安全回退）

```
